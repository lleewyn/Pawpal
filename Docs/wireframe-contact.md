# Wireframe: Trang Liên Hệ (Contact Us)

Trang liên hệ được thiết kế theo phong cách Minimalist & Editorial. Bỏ hoàn toàn các thẻ (cards) đóng khung cứng nhắc, bản đồ nằm gọn gàng bên trong khung giới hạn, tất cả nội dung được canh giữa gọn gàng trong `container-xl`.

## 1. Khối Hero (Nhẹ nhàng, Gọn gàng)

```text
[ Container-xl ]
--------------------------------------------------
|                                                |
|           HÃY TRÒ CHUYỆN VỚI CHÚNG TÔI         |
|     PawPal luôn sẵn sàng lắng nghe bạn 24/7    |
|                                                |
--------------------------------------------------
```
*(Khối này có thể dùng một màu nền xám cực nhạt hoặc một tấm ảnh nền với độ mờ tinh tế).*

## 3. Khối Bản đồ (Nằm gọn trong Container)

|                                                |
|              [ BẢN ĐỒ GOOGLE MAPS ]            |
|       (Hiển thị ghim vị trí các chi nhánh)     |

*(Bản đồ được bo góc nhẹ, nằm thanh lịch ngay giữa trang, bằng đúng chiều rộng của các khối trên).*
