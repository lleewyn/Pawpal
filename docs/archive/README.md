# Tài liệu lưu trữ

Các file ở đây được giữ để đối chiếu lịch sử, không dùng làm trạng thái hoặc hướng dẫn triển khai hiện tại.

- `migration/`: các kế hoạch self-host, chuyển Cloud, nhập và đối soát dữ liệu đã hoàn tất.
- `database/`: thiết kế và enum cũ trước bản 3NF V1.
- `proposals/`: đề xuất chấm công/lương/thưởng đã được người dùng để sau.
- `chatbot/`: nhật ký thay đổi cũ.
- `reference/`: tài liệu đầu vào cũ.

Tài liệu hiện tại nằm trong [mục lục chính](../README.md).
