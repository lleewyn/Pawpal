Kiểm tra Logic:

Hướng dẫn Debug:

  1. Mở Browser DevTools (F12)
  2. Vào tab Console
  3. Click vào một link test ở trên
  4. Xem console logs xuất hiện gì:
    • ✓ Product found: = Thành công
    • ❌ Product not found = Sẽ redirect sau 2 giây
  5. Nếu vẫn bị redirect ngay lập tức:
    • Hard refresh: Ctrl + Shift + R (Windows) hoặc Cmd + Shift + R (Mac)
    • Clear cache: DevTools → Network tab → Disable cache (checkbox)
    • Hoặc xóa cache browser: Settings → Clear browsing data
